# Asset sources and licences

Updated 2026-09-25 for the v2 overhaul (original "inspired-by" world: the Brightwater, the Admiralty, the Redtide Corsairs, the Gloam Wraiths). This file is generated by `node scripts/assets/write-ledger.mjs` from the asset manifests and `scripts/assets/generation-log.json`; edit those, not this file. Player-facing credits: [public/credits.html](public/credits.html).

## Rules

- Allowed: CC0, CC BY (CC BY-SA only where unavoidable; the adapted file keeps CC BY-SA). Not used: CC BY-NC/ND, "Sketchfab Standard/Editorial", anything that shows signs of extraction from a commercial game (see [the audit](docs/aaa-overhaul/audits/assets-and-licensing.md)).
- Every third-party or generated runtime file is listed below with author, source, licence and changes. Source downloads are kept out of the repository; the manifests record their SHA-256 (`sourceSha256`) next to the runtime file hash.
- Text we author (file names, keys, in-game names, credits wording) uses no franchise names. Titles of third-party uploads are quoted here only to identify the source.
- Never commit API keys, tokens or signed download URLs.

## Rebuild

1. Install the Node tooling outside the repo (package.json stays untouched): `mkdir -p /tmp/cruise-asset-tools && cd /tmp/cruise-asset-tools && npm init -y && npm i @gltf-transform/core@4.5.0 @gltf-transform/functions@4.5.0 @gltf-transform/extensions@4.5.0 meshoptimizer sharp draco3dgltf`.
2. Put the sources under `$CRUISE_ASSET_SRC` (default `/tmp/cruise-asset-work`): Sketchfab downloads in `src/<uid>/source.glb` (official download API), Meshy outputs in `meshy/<key>.glb`, the kits in `kenney/` and `quaternius/`. Check each file against `sourceSha256` in the manifests.
3. `node scripts/assets/fleet/build-fleet.mjs [key…]`, then `--manifest`; `node scripts/assets/icons/slice-icons.mjs <sheet-dir>`; `node scripts/assets/write-ledger.mjs`.
4. Review: `node scripts/assets/render-sheet.mjs --out output/ovh-assets/<name>.png public/assets/fleet/*.glb` (add `--lineup` for a true-scale row) and `node scripts/assets/icons/icon-sheet.mjs output/ovh-assets/icons.png`.

The older Sketchfab intake scripts (`download-sketchfab.py`, `prepare-sketchfab-blender.py`, `build-sketchfab-runtime.py`) produced the kept hero ships and are not used for v2 assets.
